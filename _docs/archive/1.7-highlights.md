# New features

## Updated admin interface

You can now assign users directly from an archive view:

![](../../assets/images/1.7-highlights/demo-tilganger.png)

And assign archives directly from a user view:

![](../../assets/images/1.7-highlights/bruker1-tilganger.png)

## Tab based navigation

![](../../assets/images/1.7-highlights/sakila-page1.png)

## Plus button

New items are created with the plus button on the bottom right side of the page.

![](../../assets/images/1.7-highlights/plus-button.png)

## Archiver role expanded

- See all users and all companies
- Manage any archive
- Delete a company

## Header and footer partials

A Ruby view can now render the header and footer fields defined in XML with `render 'header'` and `render 'footer'`.

## Clone templates from URL

Clone templates directly from a URL, in addition to the git server at [maler.kdrs.no](https://maler.kdrs.no).

![](../../assets/images/1.7-highlights/clone.png)

## Streamed downloads

Downloads of LOBs and zip files are now streamed, reducing memory usage and improving performance for large files. Download checkboxes are now checked by default.

## Enhanced statistics

- Grouped by activity type (view/download)
- Period selector: 1 month, 3 months, 1 year, all time

![](../../assets/images/1.7-highlights/statistikk.png)

## Validation improvements

- Validations show the path to the file with the error
- Detects foreign keys without a parent record

## Security scanning

Added bundler-audit as a security scanner for dependencies.

# Fixes

- Security fix for the archiver role
- Renaming a company in the cloud now requires admin
- The statistics view was not scoped to the current archive
- User catalog update was allowed when `LOCAL_LOGIN=false`
- MIME type detection was not running for Solr LOBs
- Redirect loop when the redirected page also had an error
- Crash when the template manager was loaded concurrently
- Print and download buttons are now translated
- When adding users or creating grants, full name and email are shown instead of company name, and the list is sorted
- MySQL tables are converted from utf8mb3 to utf8mb4
- Duplicate tag detection
- The `row` tag with value `max` will fetch the maximum number of rows (currently 10.000)

# Deprecated

- The `customview` tag is deprecated. Use [`rubyview`]({{ 'xml/rubyview' | relative_url }}) instead.
- The logo feature has been removed. We are considering built in logos.
- Edit mode deprecated
